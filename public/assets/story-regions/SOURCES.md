# Regional story artwork

All talking expressions are unmodified authentic PMD Collab 40 × 40 pixel portraits. Only original emotion files actually present in the upstream directory are mapped. Missing expressions fall back to that Pokémon’s original Normal portrait in the game. No expression art is fabricated. Full bodies reuse locally cached PokeAPI sprites. Alpha-frame metadata describes the existing files without changing any pixels.

PMD Collab artwork is under [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/); the exact upstream license and contributor display-name mapping are retained here. Pokémon rights remain with the original rights holders. Exact source URLs, upstream commits, Git blob hashes and per-expression credits are in `sources.json`; each character folder retains its upstream full credit history.
