# Story artwork sources and credits

Talking portraits use authentic, unmodified PMD Collab expressions. Each emotion is an actual upstream filename and was verified as a 40 × 40 PNG. Where a character only has Normal, no alternate emotion artwork is invented. This update adds the Kanto cast while retaining previous local assets for save compatibility.

PMD Collab contributions use [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/). See `PMD-LICENSE.md` for the upstream license and disclaimer. Original Pokémon artwork and trademarks remain the property of their respective rights holders. `sources.json` retains exact URLs, contributor metadata and Git blob hashes. Full upstream credit histories remain beside each character’s portraits, with creator display names in `credit-names.txt`.
