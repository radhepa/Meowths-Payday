# Regional Pokémon artwork sources

All manager portraits are authentic, unmodified 40 × 40 PMD Collab Normal expressions. Full-body sprites use the exact PokeAPI sprite URLs returned by its Pokémon endpoint. Every roster entry was checked against the Pokémon-species generation field, not inferred from appearances or regional variants. New API responses and species data are cached in `api/`; existing pixel assets are reused.

PMD Collab contributions use [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/), with the repository disclaimer retained in `PMD-LICENSE.md`. Pokémon artwork and trademarks remain the property of their original rights holders. `sources.json` contains exact URLs, contributor identities, Git blob hashes and pinned repository commits. `credit-names.txt` and each `credits.txt` retain upstream attribution. PokeAPI sprites are locally cached in accordance with the [fair-use policy](https://pokeapi.co/docs/v2#fairuse).
